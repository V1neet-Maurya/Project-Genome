# Genome

A modern MERN project-management and developer intelligence platform.

## Stack
- Frontend: React + Vite + JavaScript + Tailwind CSS v4 + Redux Toolkit + React Router + Recharts
- Backend: Node.js + Express + MongoDB + Mongoose + JWT

## Run

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

Copy `backend/.env.example` to `backend/.env` and set `MONGO_URI` and `JWT_SECRET`.
